15. Project API Flow

sequenceDiagram
    participant User
    participant API as POST /ask API
    participant Graph as Corrective RAG Graph
    participant Index as Vector/Hybrid Index
    participant Models as Grader/Rewriter/Generator/Critic
    participant Logs as Trace and Eval Store

    User->>API: question, user_id, tenant_id, role
    API->>Graph: validated request with identity context
    Graph->>Index: retrieve with ACL, tenant, metadata filters
    Index-->>Graph: candidate chunks
    Graph->>Models: rerank and grade evidence
    Models-->>Graph: strong, ambiguous, or poor decision
    alt strong evidence
        Graph->>Models: generate cited answer
        Models->>Models: faithfulness and citation critique
        Models-->>Graph: supported answer
    else weak evidence
        Graph->>Models: rewrite query or choose fallback
        Models-->>Graph: revised query or fallback decision
        Graph->>Index: retrieve again
    else insufficient evidence
        Graph-->>API: abstention response
    end
    Graph->>Logs: trace_id, scores, chunks, decision path, latency, cost
    API-->>User: answer, citations, confidence, retrieval_decision, trace_id
