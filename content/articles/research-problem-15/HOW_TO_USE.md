# Upload to GitHub
1. Extract the ZIP.
2. Create a GitHub repository.
3. Upload the **contents** of this directory (README.md, assets/, diagrams/, source/).
4. GitHub will show the local images and Mermaid fenced architecture in the README.
5. Edit `.mmd` files in a code editor or at https://mermaid.live/ and update the corresponding README diagram when desired.

The PNG/SVG images are static exports; their `.dot` sources are editable. `.mmd` files hold the editable Mermaid architecture, independently of exports.
