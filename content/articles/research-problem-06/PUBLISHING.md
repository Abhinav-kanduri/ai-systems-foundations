# Publishing

Upload the **contents** of this folder to the root of your GitHub repository. GitHub renders Markdown Mermaid fences. PNG and SVG files are committed locally, so image links are portable. Modify `.mmd` files in `diagrams/` and update corresponding inline Mermaid blocks in the README when you change the architecture. PNG/SVG are static snapshots of the same conceptual architecture.

The research text is reproduced from the uploaded source. Links and research claims have not been independently validated in this package.
