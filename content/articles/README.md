# Blogs and technical articles

Focused writing that explains a problem, develops a technical argument, or walks
through an engineering decision belongs here.

No articles have been added yet. Start with the
[article template](../templates/article.md), create `<slug>/README.md`, and add a
link here when it is ready for readers.

Use this table when adding the first article:

```markdown
| Title | Type | Topic |
| --- | --- | --- |
| Article title linked to its README | Technical article or blog | Primary topic |
```

See the [writing conventions](../README.md) and [longer guides](../guides/README.md).
