# Blogs and technical articles

Write focused publications in `<slug>/README.md`, using validated frontmatter.
Keep supporting images in that article's `assets/` directory and reproducible
examples in `examples/`.

The website generates its article list automatically. Use the
[publishing commands and metadata template](../README.md), or copy the
[article template](../templates/article.md).

Browse the [local publications library](http://localhost:8000/publications/).
Longer learning resources live under [Guides](../guides/README.md).
