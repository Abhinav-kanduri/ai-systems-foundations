# Publishing guide

1. Create a GitHub repository and upload the files and folders from this directory (not only README.md).
2. Keep relative paths intact: `README.md` references `assets/` and `diagrams/`.
3. Preview the README on GitHub. Mermaid blocks render without a separate plugin.
4. Edit the `.mmd` files to revise diagrams and use the Graphviz `.dot` files to regenerate downloadable PNG and SVG versions.
5. Check the linked research sources again before republishing time-sensitive claims.
