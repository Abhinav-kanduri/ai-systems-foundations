## Overview

This repository contains structured lecture notes on **Generative Artificial Intelligence** and **Large Language Model Engineering**.

The notes explain core concepts from deep learning foundations to modern LLM training, distributed systems, preference optimization, inference systems, evaluation, debugging, and safety.

The main document is:

- [End-to-End Concepts](./End-to-End-Concepts.md) (This .md will keep getting updated)
- [Deep Learning Foundations](./Deep-Learning-Foundations.md)

## Purpose

The goal of these notes is to help learners understand not only *what* each Generative AI and LLM concept means, but also:

- Why the concept became necessary
- What practical problem it solves
- Where it helps in real engineering systems
- Where it can fail or become difficult
- What advantages and disadvantages engineers should understand

These notes are written for students, developers, AI engineers, educators, and business professionals who want a practical understanding of modern LLM systems.

Each concept is explained using four practical teaching lenses:

   Highlights where the concept is useful.

   Explains limitations, risks, or real-world challenges.
