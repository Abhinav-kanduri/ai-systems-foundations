# GenAI Career Navigator — Custom GPT Package

Paste-ready configuration for building the **GenAI Career Navigator** Custom GPT
in the ChatGPT GPT Builder.

## Files

| File | Where it goes in GPT Builder |
|------|------------------------------|
| `01-name.txt` | **Name** field |
| `02-description.txt` | **Description** field (under 300 chars) |
| `03-instructions.md` | **Instructions** box |
| `04-conversation-starters.txt` | **Conversation starters** (one per line) |
| `05-capabilities-and-knowledge.md` | Capabilities toggles + files to upload |

## Quick setup

1. Open ChatGPT → **Explore GPTs** → **Create**.
2. Go to the **Configure** tab.
3. Copy each file's contents into the matching field above.
4. Turn ON: **Web Search**, **Canvas**, **Code Interpreter & Data Analysis**.
5. Upload the knowledge files listed in `05-capabilities-and-knowledge.md` when ready.
6. Save → set visibility (Only me / Anyone with link / Public).
